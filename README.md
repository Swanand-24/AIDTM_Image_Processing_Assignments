**Student Name:** Swanand Wirkar

## Overview
This practical file explores image processing techniques for edge detection, noise analysis, compression, texture analysis, and image segmentation using Python and machine learning libraries.

## Practicals Included
1. **Comparative Edge Detection:** Apply Sobel, Laplacian, and Canny operators to natural images.
2. **Noise Sensitivity Experiment:** Add Gaussian and salt-and-pepper noise and evaluate edge detection performance.
3. **Compression Ratio Comparison:** Compare Run-Length Encoding (RLE) and Huffman Coding.
4. **JPEG Block Artifact Analysis:** Implement block-based DCT and quantisation and evaluate PSNR and SSIM.
5. **Texture-Based Segmentation:** Extract GLCM features and segment textures using K-means clustering.
6. **Multi-Feature Disease Segmentation:** Combine intensity, Sobel gradient magnitude, and local texture variance to segment plant disease images.

## Technologies Used
- Python
- OpenCV
- NumPy
- Matplotlib
- Scikit-image
- Scikit-learn
- Jupyter Notebook

## Installation
Install the required libraries using:

```bash
pip install opencv-python numpy matplotlib scikit-image scikit-learn
```

## Usage
1. Clone or download this repository.
2. Open the required `.ipynb` notebook in Jupyter Notebook or Google Colab.
3. Place the required input images in the notebook's working directory.
4. Run the notebook cells sequentially.
5. Review the generated visualizations, measurements, and analysis.

## Learning Outcomes
- Compare edge detection operators and their noise sensitivity.
- Evaluate lossless compression techniques and compression ratios.
- Understand DCT-based image compression and compression artifacts.
- Extract texture features using Gray-Level Co-occurrence Matrices (GLCM).
- Apply K-means clustering to image segmentation tasks.
- Analyze the strengths and limitations of intensity, gradient, and texture features for disease detection.
